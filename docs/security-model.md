# セキュリティモデル

Bubble Matrix Mapはローカルで決定的に動作するCLIであり、マルチユーザーサービスではありません。

信頼できるローカル入力だけを使用してください。
CLIはCSV、TSV、`.xlsx`を同じプロセス内で解析します。
Excelでは最初の可視ワークシートを読み、文書化した上限内で選択データ全体をメモリへ読み込みます。

共有書込場所のファイル、レビューしていない第三者提供ファイル、管理者実行を必要とするパスは使用しないでください。
CLIは外部APIを呼ばず、入力をネットワークへ送信しません。
成果物の競合置換には`--force`が必要で、出力ファイルは宣言したoutput root内に限定されます。

output-root lockは、同じ信頼済みローカルディレクトリを使う正常なCLIプロセス同士を調整します。
生成中に別プロセスがoutput root、その親、lockをrename、置換、削除できる状況に対する安全境界ではありません。
管理者権限を使わない場合でも、信頼できないプロセスが書き込めるoutput rootは非対応です。

既定の機械可読receiptと結果JSONは、basenameまたはoutput rootからの相対パスを使います。
絶対パスが必要なローカル自動処理だけ、`--include-paths`を明示してください。
このオプションを使ったログには利用者名やプロジェクト名が含まれ得るため、機密情報として扱います。
